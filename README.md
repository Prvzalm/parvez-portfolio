Design Philosophy

I didn't want this to be another:

«"Hi, I'm a developer. Here are 17 cards with my skills."»

Instead, the idea was to create something that communicates both sides of me:

The engineer
who cares about architecture, performance and solving problems.

The human
who enjoys chess, piano, experimentation and learning new things.

The result is intentionally playful, but the work remains the center of the experience.

Running Locally

Clone the repository:

git clone https://github.com/Prvzalm/MainWebSite.git

Navigate into the project:

cd MainWebSite

Install dependencies:

npm install

Start the development server:

npm run dev

Open:

http://localhost:3000

---

Environment Variables

Create a ".env.local" file if environment-specific configuration is required:

NEXT_PUBLIC_SITE_URL=
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=

Only add variables that are actually required by the current implementation.

Never commit secrets or private API keys.
